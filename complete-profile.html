Kailangan ng student account?

Ang school admin ang gagawa ng iyong account gamit ang iyong LRN at username. Hindi kailangan ng Gmail o email.

Hingin sa admin ang iyong username at password. Maaari kang mag-login gamit ang iyong 12-digit LRN o username at password.

Nakalimutan ang password? Kausapin ang school admin para ma-reset ito.
