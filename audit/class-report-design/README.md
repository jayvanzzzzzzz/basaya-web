Class Report design verification

Screenshots, workbook, and PDF are generated by tools/class-report-design-browser.cjs
using an isolated test roster. They contain test data, not live student records.
The application uses its existing Firebase reads and reporting calculations.

Run the browser checks from the project root:

    Invoke-WebRequest -Uri 'https://cdn.jsdelivr.net/npm/exceljs@4.4.0/dist/exceljs.min.js' -OutFile 'audit/class-report-design/exceljs.min.js'
    node tools/class-report-design-browser.cjs

The local ExcelJS cache is the unmodified library used by the production exporter.
It lets the browser test verify genuine workbook generation without external
browser network access. It is excluded from version control.
